## Installation

To install paleo-emu we recommend using [Miniconda](https://www.anaconda.com/docs/getting-started/miniconda/main), and creating a new environment for your project:

```
cd paleo-emu 

conda create -n paleo-emu python=3.11 -y
conda activate paleo-emu

pip install -e .
```
